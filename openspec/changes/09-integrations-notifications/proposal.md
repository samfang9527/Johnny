# Proposal: Integrations and Notifications

## Why

Johnny becomes valuable when training data arrives automatically and recommendations can reach the user proactively.

## What Changes

- Add a provider integration boundary for activity data.
- Add sync and ingestion workflow records.
- Add notification intent and LINE delivery boundary.
- Keep manual data input as fallback.

## Capabilities

### New Capabilities

- `integrations-notifications`

### Modified Capabilities

- `activity-health-domain`
- `recommendation-approval`
- `agent-runtime-tools`

## Impact

This enables event-driven analysis and proactive communication for MVP.
