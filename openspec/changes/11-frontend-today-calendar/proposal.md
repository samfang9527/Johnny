# Proposal: Frontend Today and Calendar

## Why

Today is Johnny's primary daily habit surface. It should make the training recommendation loop visible before secondary surfaces are built.

## What Changes

- Replace scaffold starter UI with the product app shell.
- Add Today page backed by API data.
- Add training calendar view.
- Add recommendation action controls.

## Capabilities

### New Capabilities

- `frontend-today-calendar`

### Modified Capabilities

- `backend-api` is consumed by frontend API client methods.

## Impact

This provides the first complete user-facing MVP workflow.
